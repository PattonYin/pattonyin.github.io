# Geometry provenance

Source-package provenance from `X:/code/ocean/hardware/kiwi_robot_share`.
Paths below refer to that package. The website uses only simplified visual GLBs
and the URDF joint frames; raw CAD, collision geometry, and simulation code are
not copied into the site. Simplification targets 6,000 faces per visual part
(12,000 for the detailed servo),
with the supplied URDF colours and a separate mesh for each moving jaw.

- Project: [KIWI](https://lingfeng.moe/KIWI/)
- Asset: [public robot gripper GLB](https://lingfeng.moe/KIWI/viewer-demos/assets/gripper.glb)
- Local original: `reference/kiwi_robot_original.glb`
- Original asset SHA-256:
  `1c1b37481f4fd197e54fe07db252cb9a379583e04f6323f85c8dc1c14f32d751`

The original GLB is retained unchanged. It supplies the gripper, servo, camera,
hardware, and original KIWI mounting plate geometry. Exported meshes are transformed
into the flange or closed-jaw frames. The conversion omits 40 disconnected non-solid
faces on the left gear and 42 on the right. The source gear-tooth interference is
preserved and measured in `exports/validation.json`.

The orange KUKA adapter is an added prototype, generated by `scripts/build_model.py`.
The articulated URDF, estimated inertials, coarse collision meshes, mounting helper,
viewers, and validation scripts are also additions to the static source model.
This is not an official KIWI CAD release and includes no original parametric CAD
history or STEP model.

The example KUKA arm is loaded from the `pybullet_data` package installed with
PyBullet; its arm assets are not copied into this ZIP. KIWI attribution does not
apply to that separate example asset.

No upstream license grant is bundled with the downloaded KIWI GLB. This package
records attribution and does not assign a new license to KIWI's geometry. Preserve
this provenance and record which parts you change when sharing revisions.
